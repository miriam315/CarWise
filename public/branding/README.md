# Strauss logo

`strauss-logo.png` is the original, unmodified 220 × 151 pixel logo embedded
in the user-provided Strauss hackathon challenge PDF
(`הנחיות האתגר - שטראוס (PDF) (1).pdf`, page 1, image object 15).
It was extracted losslessly using `pdfimages -png`.

The file is served locally; displaying the logo makes no third-party request.
Keep its original colors and aspect ratio. The logo and trademark belong to
Strauss. The application identifies the collaboration as a hackathon challenge.
