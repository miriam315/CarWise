# CarWise · יועץ הרכב של שטראוס

מערכת הדגמה עובדת בעברית ו־RTL להשוואת השפעת רכב החברה על שכר הנטו. מבוססת על קובצי האתגר שהועלו, עם הפרדה בין ממשק השיחה למנוע החישוב.

## הפעלה

דרישות: Node.js 22+‎ (נבדק על 24), npm, Python 3.12+‎. אין צורך במפתח API, במסד נתונים חיצוני או בחבילות Python להפעלה.

```bash
cd /workspace/CarWise
npm ci --cache /workspace/.npm-cache
npm run build
npm start
```

השרת מגיש את האפליקציה ואת ה־API בפורט **8000**. בדיקת מוכנות: `curl --fail http://127.0.0.1:8000/api/health` — מחזירה `status: ok` ו־`records: 77988`.

לפיתוח עם רענון אוטומטי, השאירו את שרת Python פועל והריצו בטרמינל נוסף `npm run dev`. Vite פועל בפורט **5173** ומעביר קריאות `/api` לשרת Python בפורט 8000.

לשינוי פורט השרת: `CARWISE_PORT=8002 npm start`. בפיתוח יש לעדכן גם את יעד ה־proxy ב־`vite.config.ts` אם משנים את פורט ה־API.

## מה עובד

- דשבורד אישי, עברית ו־RTL, עיצוב רספונסיבי, פונטים מקומיים ותמונת רכב שנוצרה להמחשה.
- כל 6 עובדי האתגר, טופס עריכה, סימולציה מחדש ושמירת הפרופיל המקומי בדפדפן.
- קטלוג של 20 דגמים (18 בקבוצות א–ד ו־2 משפחתיים; למרות תיאור של 22 בחלק מהחומרים, האקסל כולל 20).
- סינון לפי יצרן/דגם/הנעה, בדיקות קבוצת זכאות, מסלול משפחתי וויתור לפי עיסוק.
- טעינת **כל 77,988 הרשומות** מהמאגר הרשמי, ושאילתה לפי מפתח מלא: שנת מס, שנת רישום, סוג רכב, קוד תוצר וקוד דגם. קודי רכב נשמרים עם אפסים מובילים.
- חישוב חודשי ב־Python `Decimal`: מס הכנסה, זיכויים, פנסיה, קרן השתלמות, ביטוח לאומי ובריאות, השתתפות, אחזקה ופער במסלול משפחתי.
- גילום חשמל לקבלת 250 ₪ נטו, ללא עיגול ביניים. עיגול לתצוגה בלבד.
- שיחה מקומית מבוססת כללים: בחירת רכב, בקשת חלופה חשמלית או ויתור, הבהרת רכב לא חד־משמעי וחילוץ נתונים עם תווית מפורשת. למשל: `שכר בסיס 19500, פנסיה 6, קרן השתלמות 2.5, נקודות זיכוי 2.75, 4 ילדים`.
- מרכז נציגים: פתיחת פנייה על השתתפות, השהיית תוצאת החלופה, תשובה עם סכום מאושר, חישוב מחדש והמשך שיחה. SQLite שומר פניות ושיחות גם לאחר הפעלת השרת מחדש.
- פירוט חישוב והורדת CSV להשוואה.

## תסריט הצגה — 3 דקות

1. **התוצאה לפני הכול:** בחרו נועה לוי. מעבר מ־COROLLA CROSS ל־ATTO 3 מציג נטו של 11,693 ₪ במקום 11,032 ₪: תוספת 661 ₪ בחודש וכ־7,932 ₪ בשנה.
2. **הוכחת אמינות:** פתחו ״למה זה קורה?״. הציגו מפתח רשמי לרכב ופירוט ניכויים. עברו ל״מקורות וכללים״ כדי להציג מאגר מלא וגבולות החישוב.
3. **מקרה מורכב:** בחרו דוד כהן. המסלול המשפחתי מאפשר קרניבל בזכות 5 ילדים, אבל מציג ירידה של 3,522 ₪ בנטו. בקשו ביועץ לוותר על הרכב — המנוע מסרב כי זהו תפקיד שטח.
4. **אדם משלים את התמונה:** חזרו לנועה, פתחו פירוט ATTO 3 ושלחו שאלת השתתפות לנציג. הציגו שהחלופה בהמתנה. במרכז הנציגים הזינו 350 ₪ ותשובה, ואז חזרו ליועץ: השיחה ממשיכה עם נטו 11,643 ₪ ותוספת 611 ₪.
5. **גמישות:** שנו שכר בטופס או כתבו ביועץ `שכר בסיס 19500, השווה ATTO 3`. ההשוואה מחושבת מחדש.

## בדיקות

```bash
npm test
npm run build
```

10 בדיקות מנוע מכסות את ששת מקרי הייחוס, קודי המקור והנעות, גילום מדויק, ספי מס וביטוח, זכאות, ניכויים, חילוץ נתונים וקלט לא תקין.

בדיקת דפדפן אופציונלית דורשת `playwright` ו־Chromium (הבדיקה בוצעה עם הדפדפן המותקן ב־`/usr/bin/chromium`):

```bash
python3 scripts/smoke.py
```

הבדיקה מפעילה שרת מבודד בפורט 8001 עם SQLite זמני. היא בודקת עריכת שכר, סינון, מפתח רשמי, העברה לנציג, מניעת פניות כפולות, המשך שיחה, ששת העובדים, חסימת ויתור, מובייל ושמירה לאחר הפעלה מחדש. היא אינה משנה את נתוני הפניות של הדמו. צילומי מסך נשמרים ב־`.local/screenshots/`.

## הכרעות ומגבלות

- **נתוני מס:** לוחות 2025 להמחשה, כפי שמוגדר ב־`data/rules.json`; שנת מאגר הרכב היא 2026. לא מוצגת הבטחה לחישוב שכר אמיתי לשנת 2026.
- **פערי עיגול במקור:** נטו היום ונטו החלופה תואמים בכל 6 הדוגמאות. ההפרשים באקסל של רחל ואלי נגזרו מחיסור סכומים שכבר עוגלו. לפי כלל ״עיגול בתצוגה בלבד״, כאן מוצגים בהתאמה **−1,939 ₪** ו־**+722 ₪**, לעומת −1,938 ו־+721 באקסל. נוסחת המס לא שונתה לצורך התאמה.
- **שיחה:** אין מודל שפה מחובר. הנתב משתמש בכללים ותוויות מפורשות ואינו מבין כל ניסוח חופשי. אין העלאת תלושים או OCR. אין סכומים שמודל שפה ממציא.
- **טכנולוגיה:** React + TypeScript + Vite; שרת Python stdlib עם Decimal ו־SQLite. מסמך הארכיטקטורה המצורף הציע C# ו־Supabase; זו גרסה מקומית עצמאית, ללא שירותים או מפתחות חיצוניים. אפשר להחליף שכבת שיחה או התמדה בלי לשנות את כללי החישוב.
- **נתונים ואבטחה:** עובדי הדמו פיקטיביים. אין אימות, הרשאות או הפרדת גישה בין עובדים ונציגים, ואין להשתמש בגרסה זו לנתוני שכר אמיתיים. ה־API אינו חשוף כשירות מאומת. לפיילוט דרושים אימות והרשאות, מדיניות שמירת מידע, הצפנה/הקשחה וחיבור לנתוני מדיניות ולוחות מס מאושרים.
- **שמירה:** הפרופיל הערוך נשמר ב־localStorage. פניות ושיחות נשמרות ב־`.local/carwise.db`. שינוי `CARWISE_STATE_DIR` מאפשר תיקיית אחסון נפרדת. תהליכים חייבים להתחיל מחדש לאחר שחזור סביבת ענן.
- **תמונות:** איורים ותמונת רכב כלליים להמחשה בלבד, אינם תמונות יצרן של הדגמים המוצגים.

## מבנה

- `src/` — ממשק, סגנונות ואיורי רכב.
- `server/engine.py` — כללי זכאות, שליפה רשמית, חילוץ מקומי וחישוב Decimal.
- `server/app.py` — HTTP API, התמדה והמשך שיחות.
- `data/rules.json` — כללי האתגר המקוריים. שאר קובצי JSON: קטלוג, עיסוקים, עובדים ונתוני ייחוס.
- `data/tax-authority-2026.csv` — מאגר CSV מלא; הומר מ־Windows-1255 ל־UTF-8, ללא שינוי נתוני המקור.
- `data/import_sources.py` — כלי הייבוא שבוצע פעם אחת מהקבצים המצורפים. אינו נדרש להפעלה. הרצה חוזרת שלו דורשת את הקבצים המקוריים ואת `openpyxl`.
- `scripts/smoke.py` — בדיקת דפדפן וזרימת הנציג במאגר זמני.

כל משימת ענן כבר מבודדת. יש להשתמש בצ׳קאאוט הקיים; אין צורך ליצור Git worktree נוסף.
