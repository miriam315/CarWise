# תמונות רכבים וגלריות

בניהול ← קטלוג רכבים ← עריכת רכב מופיע אזור התמונות החדש.

1. מזינים מקור וקרדיט ומאשרים הרשאת שימוש.
2. בוחרים תמונות חוץ, תמונות פנים או סדרת 360°.
3. מעלים JPG, PNG או WebP, עד 12MB לקובץ. ניתן לבחור כמה קבצים יחד.
4. מסדרים או מסירים תמונות, מסיימים עריכת טיוטה ושומרים באמצעות „שמירת נתונים”, בלי גרסת מדיניות חדשה ובלי דרישת מפתח AI.

התמונה הראשונה מסוג חוץ משמשת בקטלוג ובכרטיסי ההשוואה. בפירוט החישוב
אפשר לפתוח את אותה גלריה. לרכב ללא תמונות נשאר האיור הקיים; כשל טעינה
בתמונת הכיסוי מחזיר את האיור. התמונות מסומנות להמחשה ואינן מפרט מחייב
לשנתון או לרמת גימור.

## ייבוא מ־Wikimedia Commons

באזור התמונות בוחרים חוץ או פנים ולוחצים „חיפוש תמונות בויקימדיה”. מוצגות
תוצאות עם רישיון נתמך; בוחרים תוצאה לתצוגה מקדימה, בודקים התאמה לדגם
ולשנתון, מאשרים הרשאת שימוש ולוחצים „הוספת התמונה לרכב”. לאחר מכן שומרים
ומפעילים את ההגדרות. השם באנגלית מוצע אוטומטית לדגמי האתגר, ובחירת פנים
מוסיפה `interior` לחיפוש. תמונות חיפוש נפרדות אינן יוצרות סדרת 360°.

החיפוש וההורדה מבוצעים בשרת. לא נשלח מידע על עובד. נתמכים CC BY,
CC BY-SA, CC0 ו־Public domain לפי המטא־דאטה של Commons, עם סינון סוג קובץ.
נשמרים היוצר, שם הקובץ, המקור, הרישיון והודעת התאמה לתצוגה. ההורדה מוגבלת
ל־HTTPS בדומיין `upload.wikimedia.org`, ללא הפניות; אין ייבוא מכתובת חופשית
ואין קריאה אוטומטית לכל תמונות הקטלוג. נדרשת גישת שרת לשני דומייני
Wikimedia; במקרה חסימה מתקבלת הודעה ואפשר עדיין להעלות תמונות מהמחשב.

## הגדלה, פנים הרכב ו־360°

כפתור „תמונות הרכב” פותח גלריה גדולה עם לשוניות חוץ ופנים, תמונות ממוזערות,
הגדלה עד 250%, קרדיט ומעבר בין תמונות. אפשר לסגור ב־Escape. המוקד חוזר
לכפתור הפותח, ומוגבל לתיבת הגלריה בזמן שהיא פתוחה.

ל־360° דרושים 12–48 צילומים שונים מאותו סיבוב מלא סביב אותו רכב. סדר
הקבצים נקבע לפי שמותיהם, למשל `01.jpg` עד `36.jpg`, וניתן לשנות אותו בניהול.
לעובד הלשונית מוצגת רק כשיש לפחות 12 צילומים שונים. בניהול מוצגות גם ההנחיות ומצב הסדרה. מסובבים באמצעות גרירה,
החצים או מחוון הזווית. הזווית המוצגת מניחה מרווחי צילום שווים; אין כאן
שחזור תלת־ממד מתמונה אחת, ואין סיור פנורמי בפנים הרכב. תמונות הפנים הן
תמונות נפרדות שניתן להגדיל. אין סדרות 360° מומצאות או משוכפלות מראש.

## אחסון וגבולות

הדפדפן מתאים תמונות ל־JPEG, עד 1600 פיקסלים בצלע, 1.92 מיליון פיקסלים
ועד 512KB לתמונה. השרת בודק סוג, גודל ומבנה JPEG ומסיר מקטעי מטא־דאטה,
לרבות EXIF. SVG, HTML, PDF וקישורים חיצוניים אינם מתקבלים כתמונות.
הבדיקה המבנית אינה פענוח מלא של כל פיקסל; תמונה פגומה שאינה ניתנת להצגה
מקבלת מצב כשל בגלריה ואינה מוצגת כתוכן פעיל.

ההעלאה זמינה רק למנהל, עם אישור שימוש, דרך `POST /api/admin/car-images`.
הקבצים נשמרים במסד כעצמים לפי SHA-256, ברשומות `car-image:...` נפרדות
ב־`carwise_rules`. הגדרת הרכב מכילה רק מזהים, סוגי תמונות וקרדיט. התמונות
נטענות לפי צורך ואינן נטענות כולן לזיכרון בהפעלת השרת; מטמון השירות מוגבל
ל־32MB. אין צורך במיגרציה חדשה או בדיסק מקומי קבוע באירוח.

`GET /media/cars/{hash}.jpg` מגיש תמונות מוצר בפומבי עם MIME קבוע,
`nosniff` ומטמון בלתי משתנה. יש להשתמש בו רק לתמונות רכב המותרות לפרסום.
אין לו קשר לתלושי שכר או למסמכי עובד. קיימת מגבלת 60 תמונות לרכב ו־90
העלאות בדקה למנהל. הסרת תמונה מהגלריה מנתקת את השיוך בטיוטה; העצם נשמר
במסד כדי שגרסאות קודמות של ההגדרות יוכלו עדיין להציג אותו בשחזור.

## מצב התמונות הראשוניות

בשל חסימת רשת של Wikimedia ושל Unsplash בסביבת העבודה, לא נוספו כרגע
תמונות מוצר אמיתיות מראש. לא הוחלפו תמונות אמיתיות בתמונות שנוצרו ב־AI
ולא נשתלו קישורים שלא נבדקו. נדרש מקור תמונות נגיש עם הרשאת שימוש, או
העלאה של קבצי הארגון דרך הניהול, או שימוש בייבוא Commons כאשר השרת רץ
ברשת שמאפשרת גישה אליו. הייבוא עצמו נבדק כאן מול תשובות מבוקרות; לא
נבדקה הורדה חיה מהספק החסום. בדיקות הגלריה משתמשות בתמונות צבע
סינתטיות במסד בדיקה זמני בלבד; הן אינן מופצות בקטלוג.

## בדיקות

`npm test` כולל בדיקות שמירה ושליפה לאחר יצירת שירות חדש, מזהי תוכן,
הסרת EXIF, חסימת תוכן פעיל וקבצים פגומים, גבולות גודל וממדים, ומניעת
קישורים חיצוניים ושכפול פריימים.

```bash
npm run build
npm run server:build
npm run test:e2e -- --suite car-media
```

בדיקת הדפדפן מעלה תמונות סינתטיות דרך מסך הניהול, שומרת בפועל במסד נפרד,
בודקת חוץ ופנים, הגדלה, מינימום פריימים, סיבוב בגרירה, התאמה לנייד, טעינה
לאחר רענון והפעלה מחדש של השרת, כותרות אבטחה ודחיית העלאה לא תקינה.
החבילה נכללת גם בהרצת GitHub Actions הרגילה.

## ייבוא למספר רכבים

בקטלוג הניהולי, אזור הייבוא המרוכז מקבל עד 60 תמונות או תיקייה. משתמשים בשמות `CAR-01__exterior__01.jpg` ובתיקיות `CAR-02/interior/01.jpg` או `CAR-03/spin/01.jpg`. רכב לא מזוהה מחייב בחירה מפורשת בטבלה; אין ניחוש לפי שם דגם משותף לשנתונים שונים. אפשר לתקן סוג ושיוך לפני העלאה. הקרדיט ואישור הזכויות חלים על כל הבחירה. תמונות שהושלמו לפני כשל נשארות בטיוטה; אפשר לשמור אותן ולנסות שוב את היתר. המערכת מנכה כפילויות לפי מזהה תוכן ואותו סוג תצוגה. יש לשמור את הנתונים אחרי ההעלאה כדי לפרסם.
