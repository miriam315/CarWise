# תיקון ביטול OCR בדפדפן — 22 באוקטובר 2026

## הכשל ששוחזר

בהרצת GitHub Actions מספר `39767751559`, משימת `application` נכשלה
בבדיקות innovations עם השגיאה:

```
Cannot read properties of null (reading 'postMessage')
```

בדיקות החילוץ עצמן מצאו את כל שבעת השדות ב־PDF וב־PNG. השגיאה התרחשה
בשל ביטול פעולה, ולא בשל טעות בתוצאות החילוץ או חיבור למסד.

ב־Tesseract.js 6, קריאה ל־`recognize(canvas)` מתחילה הכנה אסינכרונית של
התמונה באמצעות `toBlob` ו־FileReader. אם המשתמש מבטל בזמן ההכנה, ה־worker
עלול להיסגר לפני שהספרייה שולחת את משימת הזיהוי. כשההכנה מסתיימת באיחור,
הספרייה מנסה `postMessage` על worker שכבר אינו קיים.

נוספה בדיקת דפדפן שעוצרת בכוונה את callback הכנת התמונה, מבטלת את הפעולה
ומשחררת אותו רק אחרי הביטול. לפני התיקון היא נכשלה עם אותה שגיאה בדיוק;
המחסנית הצביעה על `recognize` של Tesseract. אין תלות בעיכוב שרירותי של
1.5 שניות או במהירות המעבד כדי להגיע לתנאי הכשל.

## השינוי

התמונה מוכנה מראש כבתים של PNG ללא איבוד מידע, עם טיפול בביטול, ורק אז
מועברת ל־Tesseract. בזמן ההכנה אפשר לבטל בלי לפתוח משימת OCR; callback
שחוזר אחרי ביטול אינו ממשיך לקרוא את המסמך או שולח אותו לעיבוד.
אותם בתים משמשים גם למעברי הזיהוי הנוספים.

נוספו בדיקות ביטול בין שלבי הזיהוי, טיפול בהבטחות שמסתיימות באיחור וניקוי
משאבים ללא דחיות בלתי מטופלות. סגירת ה־worker מאפשרת למיקרו־משימה שכבר
תוזמנה להסתיים לפני הסגירה. הביטול עצמו עדיין מסמן מיד את הפעולה כמבוטלת.

לא הוסתרו שגיאות הדפדפן ולא הוסרו האימותים. הבדיקה אוספת כעת גם מחסניות
קריאה לקובץ הראיות וללוג הכישלון. אין העלאת מסמך או מעבר אוטומטי לחילוץ
בשרת בעקבות ביטול.

## בדיקות

- שש בדיקות חדשות: ביטול מוקדם, ביטול בזמן `toBlob`, ביטול בזמן קריאת
  הבתים עם השלמה מוצלחת או נכשלת באיחור, הכנה מוצלחת וכשלי הכנה.
- בדיקת דפדפן דטרמיניסטית מול Tesseract האמיתי ומסד בדיקה זמני.
- חילוץ כל שבעת השדות ב־PDF וב־PNG נבדק מול הערכים הצפויים.
- הפקודה המלאה של משימת CI: `npm run test:e2e -- --quick`.

בדיקות היחידה נכללות ב־`npm test`, ובדיקת הדפדפן נכללת ב־GitHub Actions.
תוצאות מקומיות אינן אישור שההרצה החדשה ב־GitHub הושלמה; יש לבדוק את
תוצאת ההרצה של קומיט התיקון, ולא להריץ מחדש את הקומיט הישן שנכשל.
