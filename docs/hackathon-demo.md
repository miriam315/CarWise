# הדגמת CarWise — מהשאלה להחלטה

הציגו בסביבת הדגמה נפרדת ועם תלושים סינתטיים. עובד ונציג נכנסים בחשבונות נפרדים בקישור הענן; החלפת זהות במסך ההדגמה המקומי אינה הוכחה להתחברות אמיתית.

## הכנה

- בניהול → ספקי AI, בחרו מודל תומך PDF ותמונות לשירות `payslip` והגדירו מפתח תקף. בפרומפטים ותלושים הפעילו את השירות ושמרו. בדקו חילוץ אמיתי על תלוש סינתטי לפני ההצגה; בדיקת חיבור טקסטואלית לבדה אינה מוכיחה תמיכה במסמכים.
- הכינו עובד סינתטי בעיסוק מנהל/ת מוצר עם ארבעה ילדים ורכב COROLLA CROSS, כשהשכר חסר. הכינו את `examples/payslips/complex/01-complex-monthly.pdf`.
- הגדירו את השתתפות העובד ב־ATTO 3 כלא ידועה בסביבת ההדגמה בלבד. הכינו לנציג תשובת הדגמה של 300 ₪ בחודש.
- בדקו קישור ציבורי עם `npm run verify:cloud -- https://YOUR-HOST`. הבדיקה לקריאה בלבד; היא אינה בודקת התחברות או ספק AI בתשלום.

## הסיפור

1. העובד שואל מה יקרה לנטו במעבר לחשמלי. המערכת מבקשת רק את השכר החסר ואינה מציגה נטו סופי לפני השלמת הנתונים.
2. בוחרים תלוש סינתטי. מראים שאין בקשת העלאה בזמן הבחירה. משחירים שם/מזהים, בודקים כל עמוד ויוצרים עותק חדש. מראים את התצוגה לפני שליחה ואת האישור המפורש לספק. מבהירים שהשחרה אינה אנונימיות ושמדיניות הספק חלה על העותק.
3. מחלצים, בודקים את השדות מול התלוש, משלימים חסרים, מסמנים ומעבירים לטופס. רק אחרי שמירה וחישוב מחדש הם נכנסים לחישוב.
4. בודקים ATTO 3. השתתפות לא ידועה יוצרת שאלה לנציג ותוצאה מותנית, בלי נטו סופי מומצא. הנציג מאשר 300 ₪, והעובד ממשיך באותה שיחה.
5. מציגים את פער הנטו ואת שלושת גורמי השינוי. המספרים מחושבים בקוד; ה־AI אינו קובע נטו או כללי זכאות.
6. שומרים בחירה למעקב ומראים את מעבדת התרחישים, החודשים החריגים ואת תצוגת הנייד.

זמן תגובת AI תלוי במודל ובספק; מדדו אותו לפני האירוע, בלי להבטיח SLA מתוך בדיקה מקומית.

## מה הבדיקות מוכיחות

`npm run verify:judges` מריץ תסריט מלא מול שרת ו־PostgreSQL מקומיים מבודדים. תשובת חילוץ התלוש מבוקרת; אין בה קריאת ספק בתשלום. `npm run verify:payslips` מאמת השחרה צרובה בפיקסלים, היעדר שכבת טקסט ומטא־דאטה מקוריים, אישור כל העמודים והסכמה מחדש לאחר שינוי. מתאמי ספקים ועלויות נבדקים בנפרד בשרת.

הבדיקות אינן מוכיחות דיוק AI על כל תלוש, התחברות Supabase אמיתית או זמינות בענן. ראו [פרטיות תלושים](payslip-privacy.md) ו־[בדיקות אוטומטיות](automated-tests.md).
