# הדגמת CarWise — שלוש דקות מהשאלה להחלטה

הציגו בסביבת הדגמה נפרדת ועם נתונים סינתטיים. המטרה: עובד מבין מה יקרה
לנטו, רואה מה חסר, מקבל תשובת נציג וממשיך באותה שיחה.

## הכנה לפני השופטים

- פתחו את הקישור בענן משתי גלישות נפרדות: עובד ונציג, עם חשבונות אישיים
  שהוכנו מראש. היכנסו פעם אחת לפני ההצגה ובדקו את ההרשאות. מסך הדגמה
  מקומי שבו מחליפים עובדים אינו הוכחה להתחברות אמיתית בענן.
- הכינו עובד בעיסוק `מנהל/ת מוצר`, ארבעה ילדים עד הגיל המוגדר במדיניות,
  ורכב נוכחי `COROLLA CROSS` מהרשומה המדויקת בקטלוג. נתוני השכר יהיו חסרים
  בתחילת הסיפור; אל תסמנו אפסים כידועים בלי מקור.
- הכינו את `examples/payslips/complex/01-complex-monthly.pdf`. בניהול הפעילו
  חילוץ תלושים; בטופס העובד בחרו „במכשיר שלי”. זהו PDF צפוף עם שכבת טקסט,
  ולכן אינו תלוי במהירות OCR לתמונה בזמן ההצגה.
- הגדירו בסביבת ההדגמה בלבד את ההשתתפות של `ATTO 3` כלא ידועה. הכינו לנציג
  תשובה סינתטית: „אושרה השתתפות חודשית של 300 ₪”. השאירו את הדפדפנים פתוחים.
- החליטו אם מדגימים ספק AI פעיל או שיחה מבוססת כללים. בדקו את המודל דרך
  הניהול לפני האירוע; אם לא נבדק חי, הציגו זאת במפורש. חישוב הנטו וההסבר
  המספרי מגיעים מהקוד גם כשספק AI אינו זמין.

## תסריט להצגה

| זמן יעד | פעולה | המשפט שמסביר לשופטים |
|---|---|---|
| 0:00–0:20 | העובד שואל „מה יקרה לנטו שלי אם אעבור לחשמלי?” | „המערכת שואלת רק מה שחסר; כרגע חסר שכר, ולכן אין עדיין מספר.” |
| 0:20–1:00 | מעלים PDF צפוף, מציגים מקור, בודקים, מסמנים שדות ומעבירים לטופס. שומרים. | „המסמך נקרא במכשיר. רק הנתונים שאישר העובד נשמרים בשרת.” |
| 1:00–1:30 | בוחרים בקטלוג את ATTO 3. מציגים את הנתון החסר ואת הפנייה. | „ההשתתפות לא ידועה. אין כאן נטו סופי שהומצא על סמך אפס.” |
| 1:30–2:00 | הנציג עונה בחלון שלו עם 300 ₪. העובד חוזר לאותה שיחה ולוחץ להמשיך. | „תשובת הנציג משלימה את החישוב וממשיכה את ההקשר הקיים.” |
| 2:00–2:40 | מציגים את הכותרת החדשה ואת שלושת רכיבי ההסבר. פותחים רכיב אחד. | „זה השינוי בנטו. שלושת הרכיבים מסתכמים אליו; שווי שימוש הוא בסיס למס ואינו ניכוי נוסף.” |
| 2:40–3:00 | שומרים בחירה למעקב במעבדת ההחלטה ומרעננים. | „הבחירה והשיחה נשמרות, ואפשר לעקוב אחרי שינוי מאושר במדיניות.” |

הזמנים הם יעד לחזרה, לא הבטחת ביצועים. אם השופטים שואלים, עצרו והראו
את המקור למספר. שינוי שנתי מוצג כהפרש החודשי כפול 12 בהנחת תנאים קבועים.
אישור סכום השתתפות אינו אישור להקצאת רכב או לקיצור חוזה ליסינג.

## התוצאה החדשה שמראים לעובד

בראש הסקירה ובפירוט החלופה מוצג משפט ישיר: הנטו צפוי לעלות, לרדת או
להישאר זהה. שינוי קטן מחצי שקל אינו מוצג בטעות כשינוי של אפס.

מתחתיו שלושה רכיבים עם השפעה כספית חתומה:

1. **מסים ושווי שימוש** — הפרש מס הכנסה, ביטוח לאומי ובריאות. פירוט שווי
   השימוש הוא הקשר לחישוב המס; הוא אינו נספר כניכוי נוסף.
2. **השתתפות ברכב** — השתתפות העובד וחלקו בפער התקציב המשפחתי.
3. **החזרים והפרשות** — שינוי בשכר, אחזקת רכב, החזר חשמל ברוטו והפרשות
   העובד. המס על תוספות מופיע ברכיב המסים, ולכן אין ספירה כפולה.

הסדר נקבע לפי גודל ההשפעה. פותחים „מה נכלל ברכיב?” כדי לבדוק את פרטי
החישוב. כשחסר אישור אין הסבר כספי סופי, ויש הודעה ממוקדת על הנתון החסר.
המספרים מחושבים בשרת באותה חשבונאות decimal של מנוע השכר; אינם ניחוש AI.
רכיבים מעוגלים בנפרד בתצוגה בלבד ולכן ייתכן הפרש שקל בתצוגת הסכומים.

## חזרה אוטומטית

```bash
npm run build
npm run server:build
npm run verify:judges
```

הפקודה דורשת את סביבת בדיקות הדפדפן ו־PostgreSQL המתוארת
ב[מדריך הבדיקות](automated-tests.md). היא יוצרת מסד אקראי חדש, משלימה דרך
הממשק את החילוץ והאישור, מפנה לנציג, שולחת תשובה ממסך הנציג, ממשיכה בשיחה,
בודקת את ההסבר, שומרת בחירה ומרעננת. היא בודקת גם תצוגה בנייד והיעדר
בקשת העלאה של התלוש לשרת. המסד הזמני נמחק בסיום.

תוצרים ב־`.local/test-results/`: `judge-rehearsal.json` עם זמני שלבים,
צילומי מסך של המצב הממתין והתוצאה הסופית, וצילום תצוגת נייד. אפשר להוסיף
`--video` להקלטה, לאחר התקנת `python3 -m playwright install ffmpeg`.
הווידאו יישמר תחת `judge-video/`. הקלטה אינה תנאי להרצת הבדיקה הרגילה.

החזרה משתמשת בזהות הדגמה ובשיחה מבוססת כללים במסד בדיקה אמיתי. היא אינה
בדיקת התחברות ל־Supabase Auth המתארח ואינה בדיקת ספק AI בתשלום. זמן הריצה
המקומי שנמדד אינו SLA לענן ואינו משך הצגה אנושית. דוח תמיד שייך לגרסה שבה רץ.

## בדיקת הקישור בענן

```cmd
npm run verify:cloud -- https://YOUR-SITE
```

זו בדיקת קריאה בלבד: דף המערכת, זמינות השרת והמסד, רשומות רשמיות וקובצי
JavaScript/CSS אמיתיים. דף HTML שמוחזר במקום JavaScript אינו נחשב להצלחה.
הפקודה מדווחת זמני תגובה ומצב הדגמה/אימות. היא אינה מתחברת כעובד ואינה
מעלה תלוש, שולחת AI או משנה נתונים. ללא קישור ציבורי אין כאן ראיה שהגרסה
רצה בענן; את הכניסה ושני חלונות העובד והנציג יש לבדוק גם ידנית בקישור עצמו.

## הרחבה אם נשאר זמן

בחרו כלי אחד: נקודת איזון כשהשתתפות חסרה, חודש רגיל מול בונוס חד־פעמי,
או חישוב מחדש אחרי שינוי מדיניות מאושר. אין צורך להציג את כל מסכי הניהול.
לסיום הראו את הבדיקות ואת גבולותיהן. בדיקה על תלושים סינתטיים אינה הבטחת
דיוק לכל ספק שכר ואינה אישור אבטחה למוצר ארגוני.
